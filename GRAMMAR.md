# Grammar
```
regex: concat union;

union: '|' concat union;
union: ε;

concat: kleene suffix;

suffix: kleene suffix;
suffix: ε;

kleene: base star;

star: '*';
star: ε;

base: LIT;
base: '(' regex ')';
base: '[' negation inhalt range ']';

negation: '^';
negation: ε;

range: inhalt range;
range: ε;

inhalt: LIT rest;

rest: '-' LIT;
rest: ε;

```
